# PC 测试构建更新说明 · 2026-10-31

应用版本仍为 **1.3.2**，以 Git 提交和 Actions 运行编号区分测试构建。本次手动 Actions 只生成 Windows 附件，不创建或覆盖正式 Release。

## 目录切换

- 目录列表与来源路径绑定，切换时立即隐藏旧文件夹和项目卡片，显示加载提示，避免旧卡片拼出重复路径。
- 加载失败显示具体目录及错误，提供“重新加载”；成功重试或进入其他目录后清除旧目录报错。
- 快速切换时丢弃旧请求晚到的成功和失败结果，不覆盖当前路径的列表与错误状态。
- 文件夹笔记读取和保存错误独立显示，不因目录成功加载而隐藏；原有离开前补存规则保持。

## Windows 安装包

从本次起，Windows 本地默认构建、手动 Actions 和标签发布均只提供 **EXE（NSIS）**，不再生成 MSI。macOS 构建保持原有方式。旧 MSI 附件和已经发布的版本保留。

本地 Windows 构建可使用 `npm run tauri build`；Windows 专用配置自动选择 NSIS。Actions 同样显式指定 `--bundles nsis`，附件包含 EXE、SHA256、构建信息和本说明。

## 验证与试用

- 修复版已通过前端 16 项、Rust 19 项、后台界面 16 组检查，包含延迟加载、失败重试、返回主页及晚到请求回归，原有 12 种语言/主题/尺寸组合继续通过。
- 2026-10-31 收到用户安装试用反馈：“我试了一下没问题了”。此反馈确认本次目录切换试用，不扩大为全部硬件或全部功能验收。
- Actions 将对当前提交重新检查并构建，最终结果以该次运行状态为准。
- 安装前退出 Studio。测试包未签名，沿用原应用标识和作品库；本次不改变项目元数据和 ZIP 格式。
