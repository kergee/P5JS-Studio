# ESP32 Windows USB 串口原型

状态：源码软件原型，**真实开发板验收未完成，不属于已发布 v1.3.2 安装包**。不更改版本号，不自动发布。

## 使用与布局

软件主线仍是学生作业整理归档、离线编辑和运行 p5.js。图库没有硬件控件。Windows 编辑器的“更多工具 / More tools → ESP32”开启预览底部工具区，“调试 / Debug”和 ESP32 共用空间，不增加第三栏。默认约三分之一高；拖动分隔条或聚焦后按上下箭头调整，范围 15%～50%。折叠只隐藏内容，绿色圆点保留连接提示。

选择端口，按实际固件设置波特率（默认 115200），手动连接。8 数据位、无校验、1 停止位、无流控。没有开发板时无需打开工具，不影响普通项目。首期仅 Windows，其他桌面系统及手机不出现 USB 入口。

暂停显示只暂停监视器追加；作品继续接收数据。监视器最多 200 行，可清空。窄窗口控件换行，工具区和日志各自在内部滚动。单行发送框自动追加 LF；不要自己加换行。

## 草图 API

在运行预览中提供只读 `window.studioSerial`，无需导入库：

```js
let sensor = 0;
function setup() {
  createCanvas(400, 300);
  const unsubscribe = studioSerial.onLine((line) => {
    // 收到不含行尾 LF/CRLF 的完整字符串。JSON 也只是文本。
    const data = JSON.parse(line);
    sensor = Number(data.value) || 0;
  });
  // 如不再使用，可调用 unsubscribe()；重新运行会清理整个旧运行。
}
async function mousePressed() {
  if (!studioSerial.connected) return;
  try { await studioSerial.writeLine('LED:1'); }
  catch (error) { console.error(error); }
}
function draw() { background(sensor); }
```

- `onLine(callback)` 返回取消订阅函数。一个回调报错不会阻止其他回调；错误进入调试台。
- `writeLine(text)` 返回 Promise，串口写入成功才完成；这不保证固件执行或外设动作。需要业务确认时由固件回传 ACK，参考 LED 示例。断开、发送失败或超时会拒绝。
- `connected` 是只读布尔值；连接由用户在面板操作。草图没有枚举、打开、关闭端口的原生接口。
- UTF-8 文本行协议，接收 LF / CRLF，JSON 由作品解析。单行最大 8192 个 UTF-8 字节（不是字符数），不支持二进制。无效 UTF-8 行跳过，超长行报错并丢弃到下一 LF，随后恢复。

## 会话与连接

每次开启编辑器工具生成临时 owner，每次运行生成 run 标识。专用消息验证当前 iframe 的 `event.source`、项目、owner 和 run；新运行使用新的 iframe，拒绝旧运行、其他窗口和其他项目消息。ESP32 启用后预览使用不含 `allow-same-origin` 的 sandbox，避免草图绕过消息桥访问主窗口的原生能力。

首次启用工具会以隔离预览重新载入**上一次运行**的代码，不会偷偷执行尚未运行的修改。硬件预览不可直接使用父窗口、浏览器 localStorage 等依赖同源权限的能力；这类草图需要调整。普通模式保留原有预览方式。摄像头、麦克风及复杂第三方模型在隔离预览中的兼容性需单独验证，本期不承诺全部兼容。

同项目重新运行保留串口，旧草图订阅随 iframe 释放。手动断开、确认离开编辑器、切换项目、**成功保存重命名**或关闭窗口时释放。取消离开、改名失败或只修改尚未保存的名称不会断开。离开前等待后端释放；重复释放幂等。后端拒绝已退出编辑器的延迟连接请求，应用窗口销毁也有清理兜底。

读写、枚举、打开和释放在 Rust 后台执行，串口读超时 50ms；接收约 50ms 一批，单批最多 256 行。发送队列有界，等待写入最多 2 秒，草图消息应答上限 3 秒；排队超时的发送会取消。拔线或读写失败关闭连接，不静默重连。不会调用复位、烧录或主动切换 DTR/RTS 的操作；串口打开时驱动自身行为仍需按真实板型验收。

不修改 meta.json 格式，不持久化串口、波特率或自动连接配置；评分、收藏、版本和 ZIP 仍使用现有格式。固件和协议说明作为普通项目文件随 ZIP 归档。
