## React 检查

保持恢复状态在编辑器内，以同一保存快照决定 dirty；避免恢复确认前自动写回；资源/文件标签在 busy 时禁用。标签支持键盘并保留子关闭按钮的事件行为。图库/预览事件监听在卸载时清理。错误位置依据运行快照而非当前未运行代码，未知来源不伪造文件位置。中英文文本集中维护，主题沿用现有配色。

## 验证边界

测试只在隔离的后台浏览器上下文运行，文件保存、窗口关闭和媒体轨道使用模拟实现；没有读写真实作业、串口或摄像头。Web Audio、CodeMirror、p5.js 和浏览器全屏实现为实际执行。

未操作用户桌面，未运行安装包，也未做 Windows 原生 WebView2 的人工点击、真实媒体设备或强制断电验收。可响应运行的停止已验证；占满同一页面线程的同步死循环仍不保证能用按钮中断。图库筛选和撤销记录限当前应用/编辑会话；恢复草稿保存代码与元数据，不保存撤销历史或资源文件，不代替 ZIP 备份。未发布、未推送 GitHub。
