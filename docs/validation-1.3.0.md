## 打包程序的离线检查

停止 Vite 开发服务器后，运行使用相同源代码构建的 release QA 可执行文件。QA 配置只覆盖应用标识、窗口标题及隐藏窗口设置，用于隔离应用数据。页面来自 http://tauri.localhost，代码和运行库来自打包资产。

WebView 禁止外部主机解析，并执行离线模拟后重新加载。外部 https://example.com 请求在验证前后都失败。1.x 和 2.x 仍能运行多文件动画、加载本地图片及声音，并执行项目导出再导入。网络模拟不是物理断开网卡，也不是对所有第三方库和模型的兼容性证明。

行政解包得到的 MSI 可执行文件与独立可执行文件仅相差 Tauri 的 UNK/MSI 包类型标记，字节归一后完全一致。安装包及可执行文件哈希记录在本地 artifacts/release/sha256-manifest.json 中。

最终 MSI：artifacts/release/P5JS Studio_1.3.0_x64_en-US.msi，SHA-256：93032effa2aaba236631429fbac200c5aa200135d82f5debd7c815f7db19ff2e。

## 复现命令

在仓库目录执行：

```powershell
npm ci
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build -- --bundles msi
```

构建中的大包提示来自内置离线运行库；`.app` 标识后缀提示沿用现有应用标识，避免变更存储路径。上述提示未阻止构建。
