# PC 测试构建更新说明 · 2026-10-30

本次仍沿用应用版本 **1.3.2**，通过 Git 提交和 Actions 运行编号区分测试构建。手动运行 Actions 产出可下载附件，不创建或覆盖正式 Release；正式发布仍由 `v*` 标签触发。

## 保存与编辑

- 文件夹笔记在切换目录、打开作品和关闭窗口前补存；失败保留内容并提供重试。
- 返回图库保留当前会话的搜索、范围、评分/收藏筛选与滚动位置。
- 切换 JS 标签保留当前编辑会话的光标、滚动位置与独立撤销记录。
- 独立本机草稿恢复：重新打开时选择恢复或忽略，不自动覆盖正式项目；正式文件基线发生变化、草稿损坏或容量不足时提示。

## 运行与归档

- 预览增加停止和全屏。停止销毁预览环境，清理动画、定时器、音频和媒体资源；同步死循环卡住页面线程时不保证可通过按钮中断。
- 多文件语法、同步和异步错误显示对应文件行列，点击可跳转。
- 本地经典脚本统一在“资源 → 项目依赖（可选）”中声明、排序和移除；运行前提示缺失、远程或不可读取的脚本。文件齐全不等于模型、动态资源或在线 API 已通过离线验证。
- ml5 兼容保留，专用机器学习/3D 工具暂缓，重点继续是学生作品整理归档与离线编辑运行。

## 图标与可选 ESP32

- 桌面端统一为鸿蒙同款暖白底灰粉 p5 图标，程序与安装器均引用新图标；构建跟踪图标目录变化。
- 一并提交此前的 Windows 单设备 USB 串口原型、JavaScript 消息桥、教学示例及 C3 通用固件源码。设备连接仍需用户手动操作，不自动连接或烧录。
- Studio 与开发板通过 USB 串口通信。C3 示例固件中的可选 Wi-Fi 扫描/RSSI 只是设备侧能力，不是 Studio 的 Wi-Fi 传输接入，也不构成人体感知功能。

## 验证与安装

本地已通过 16 项前端逻辑测试、19 项 Rust 测试、13 组无窗口浏览器验证（含中英文/深浅主题/三种尺寸）、生产编译及 Windows 打包。Actions 会对当前提交重新运行测试并生成 EXE 与 MSI、SHA256 和构建信息，具体结果以该次运行状态为准。

EXE 和 MSI 任选一种，原来使用 MSI 的可继续用 MSI。安装前退出 Studio。测试包未签名；桌面人工点击、Windows WebView2、真实媒体/串口设备和固件实机行为仍需独立验收。草稿不是跨设备备份，资源操作仍沿用立即写入规则。相关边界见 [PC 验证记录](validation-pc-workflow.zh-CN.md) 和 [ESP32 原型记录](validation-esp32-prototype.md)。
