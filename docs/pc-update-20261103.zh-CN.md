# P5JS Studio 1.4.0 桌面更新

## 单文件 HTML

- 编辑器中的「导出项目 → 导出 HTML」将当前草图、所选 p5.js 运行库、本地脚本和项目资源放入一个 HTML 文件。双击文件可在浏览器的独立容器中运行作品。
- 图库中的「导入项目 → Studio HTML」可恢复独立 JS 文件、依赖顺序、p5.js 版本和资源路径。同名导入会生成带编号的副本。完整归档使用项目 ZIP。

## p5.js 网页 ZIP

- 图库中的「导入项目 → p5.js 网页 ZIP」接受含 `index.html`、经典脚本和资源的压缩包，支持一层外包装目录。
- 经典脚本按加载顺序转成可编辑标签。导入结果显示原版 p5.js 与选用的同主版本内置运行库。原 HTML、CSS 和资源作为项目文件保留，运行时使用 Studio 草图画布。
- 缺失脚本、额外远程脚本、ES 模块和越界路径会显示错误。

Windows Actions 生成 x64 EXE、SHA-256 和构建信息。用户已试用上一轮包含这两项功能的本地安装包。
