# ESP32 USB 软件原型验证记录

日期：2026-10-20。代码仍使用版本号 1.3.2，**没有发布新版本，也没有替换现有安装包**。

## 已完成的软件验证

| 验证 | 结果与证据边界 |
| --- | --- |
| `npm run build` | TypeScript 与 Vite 通过。仍有 Browserslist 数据过期和大 chunk 提示，不影响编译通过。 |
| `npm test` | 7 项通过：原有 3 项筛选测试，加 4 项串口协议／实际 bootstrap VM 测试。 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 19 项通过：原有 13 项，加 5 项串口模拟传输测试和 1 项两个真实示例 ZIP 的导入／导出／再导入测试。使用临时目录，不操作学生库。 |
| 分行与错误恢复 | 模拟测试覆盖 UTF-8 分包、粘包、CRLF、JSON 文本、无效 UTF-8、8 KB 边界、超长行恢复、发送编码、写失败、拔线、显式重连与关闭释放。没有真实驱动 I/O。 |
| 消息桥 | bootstrap VM 和浏览器测试验证来源、项目／owner／run、取消订阅、错误／超时、断开拒绝未完成请求；实际 UI 连续运行三次，旧 run 与主窗口伪造消息未调用串口写入。 |
| 接收／发送 | 浏览器 Mock Tauri：首次启用不自动连接或发送；暂停监视器时草图数值仍改变；最多 200 行；发送失败保留输入；模拟拔线后不静默重连；手动重连成功。 |
| 生命周期 | 浏览器 Mock Tauri：运行前可手动连接，随后运行仍连接；取消未保存离开不释放；确认放弃离开释放；成功保存重命名释放；窗口请求关闭时，释放命令先于 destroy 命令。Rust 模拟传输另验证释放 OS 传输对象的顺序。 |
| 界面 | 中／英文 × 深／浅色 × 800×600、1280×800、1680×1000，共 12 组检查。整窗和工具内容无横向溢出，默认约三分之一高，上限一半；键盘调整上限和折叠保留连接已检查。 |
| 示例 | 传感器示例接收模拟数值后更新画面；LED 示例点击发送 `LED:1`，收到模拟 JSON ACK 后才更新确认状态。此结果不证明真实 LED 亮灭。 |
| 普通离线项目 | 原有 DEF（1.11.13）和 GHI（2.3.4）在 ESP32 隔离预览中均加载本地 560px 图片与 0.5 秒声音；未启用工具时的运行生成画布。归档、版本、评分／收藏保留与搜索筛选由现有测试覆盖。 |
| 手机入口 | Android user-agent 模拟下不出现“更多工具”USB 入口，运行仍生成画布，串口调用数为 0。不是手机实测。 |

可重复运行的浏览器脚本与说明位于 [tests/browser](../tests/browser/README.md)，使用真实示例源码和资源、Mock Tauri 命令，不打开任何物理端口。

本地最终浏览器回执保存于 `artifacts/validation/serial-ca93304471974fcfa55477dadbaca7aa/`，包含 smoke、matrix、examples、lifecycle、mobile 和清理回执。该目录按仓库约定被 Git 忽略；其他人可运行脚本生成自己的回执。

测试中修复了首次启用工具时连续写 srcdoc 造成旧会话残留的竞态：运行／owner／项目变化时重建 iframe，并在加载及 ready 时同步连接状态。也修复了发送错误遮住后续断开状态的问题。最终完整浏览器流程通过。

## 仍未通过的实机验收

本机枚举只发现 COM1 通信端口、COM3／COM4 蓝牙串口，没有可确认的 ESP32。测试未打开这些无关端口。

- 待确定开发板型号、USB 串口芯片和驱动版本；参考接线仅针对经典 ESP32-DevKitC / WROOM-32。
- 示例 `.ino` 尚未使用真实 Arduino-ESP32 工具链编译、烧录和运行。
- 待完成传感器 → 画面、画布 → 固件 ACK → 实际 LED 亮灭两个方向。
- 待实际检查 IDE 占用端口、拔线、手动重连、连续运行、离开后其他工具可打开端口，以及驱动打开端口是否影响板子复位。
- 待在真实 Windows / WebView2 安装环境回归普通作业编辑、离线运行、归档和搜索筛选。浏览器 Mock 与 Rust 编译不能替代安装包或真实串口集成验证。

当前交付只能标记为**软件原型**。API、使用方法和待补录表格见 [ESP32 USB 文档](esp32-usb.zh-CN.md)。实机及安装环境验收完成后再决定发布版本。
